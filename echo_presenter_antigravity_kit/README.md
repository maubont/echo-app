# Echo Presenter Antigravity Kit

Carpeta base para colocar en la raíz del proyecto Echo.

## Archivos

- `echo_presenter_monolith.html`  
  HTML monolítico con landing/pitch y panel de agente preparado para backend real.

- `ECHO_APP_CONTEXT_FULL.md`  
  Contexto estratégico, funcional, de negocio y de agente IA.

- `ANTIGRAVITY_REFACTOR_PROMPT.md`  
  Prompt para pedirle a Google Antigravity que refactorice el monolito hacia una experiencia React/TypeScript profesional.

## Uso recomendado

1. Copiar esta carpeta en la raíz del repo.
2. Abrir el proyecto en Google Antigravity.
3. Pedirle que lea `ANTIGRAVITY_REFACTOR_PROMPT.md`.
4. Indicarle que use `ECHO_APP_CONTEXT_FULL.md` como fuente de verdad.
5. Convertir `echo_presenter_monolith.html` en una feature real de la app.

## Nota

El HTML no contiene API keys. Para IA real se debe crear backend seguro con OpenAI API.
